# Front Panel 1.0.0

토스 프론트 등 터치 패널에서 사용하는 Home Assistant 전용 화면입니다.
방·기기 카드·센서·날씨를 연결하고, 글라스 등 7개 테마를 선택할 수 있습니다.

![토스 프론트에 적용한 Front Panel의 글라스·블루 다크·민트·라벤더 테마](https://raw.githubusercontent.com/SeNcE-MS/front-panel-addon/main/front_panel/images/front-panel-four-themes.jpg)

왼쪽부터 **글라스 · 블루 다크 · 민트 · 라벤더** 테마입니다. 실제 Front Panel UI와 예시 데이터를 사진에 합성한 이미지입니다.

## 설치 방법

1. HA **설정 → 앱 → 앱 설치 → ⋮ → 저장소**를 엽니다.
   구버전에서는 **애드온 → 애드온 스토어**입니다.
2. 아래 주소를 추가합니다.

   ```text
   https://github.com/SeNcE-MS/front-panel-addon
   ```

3. **Front Panel**을 찾아 설치합니다.
4. 애드온의 **구성 → `viewer_ip`**에 화면을 표시할 **단말의 IP**를 입력하고 저장합니다.
5. 애드온을 시작한 뒤 **Web UI 열기**에서 방·카드·엔티티를 연결하고 저장합니다.
6. 표시 단말의 브라우저에서 아래 주소를 엽니다. `HA_IP`는 본인 HA 서버의 내부 IP입니다.

   ```text
   http://HA_IP:18764/
   ```

## 사용 안내

- **편집:** HA에서 **Web UI 열기**로 접속합니다. HA 인증을 사용합니다.
- **표시:** `viewer_ip`에 지정한 단말만 접속할 수 있습니다. 공유기에서 단말 IP를 고정하는 것을 권장합니다.
- **기기 제어:** 카드에 엔티티를 연결하고 **실제 제어 허용**을 켭니다. 조명·스위치·자동화 활성/비활성을 지원합니다.
- **테마·홈 화면:** 편집기에서 선택하고 저장합니다. 세탁·건조·할 일은 상태 표시용입니다.

## 참고

- HA OS의 앱/애드온용입니다. **HACS 저장소가 아닙니다.** 서버 아키텍처는 amd64/aarch64를 지원합니다.
- `viewer_ip`를 비워 두면 단말 직접 접속은 차단되며, HA Web UI에서만 접근할 수 있습니다.
- 단말에서 403이 나오면 `viewer_ip`가 단말의 실제 IP와 같은지 확인하세요.
- **내부망 전용 HTTP 서비스입니다. 인터넷에 포트를 공개하지 마세요.**
- 업데이트 전 편집기의 **JSON 내보내기**로 백업하고, 업데이트 후 화면을 새로고침하세요. 다른 설치 항목으로 옮길 때는 JSON을 가져오고 단말 IP·포트를 다시 설정합니다.
- 단말 OS 설치·브라우저 자동 시작·백라이트 제어는 별도 설정입니다.
