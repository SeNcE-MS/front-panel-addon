# Front Panel 1.0.0

**TOSS FRONT 단말기로 Home Assistant를 제어하는 가장 쉬운 솔루션.**

Home Assistant에 전용 화면과 편집기를 설치하고, 토스 프론트 등 브라우저가 있는 패널에서 사용하는 개인 제작 애드온입니다. 기존 HA 대시보드와 별개로 동작하며, 토스 공식 제품/펌웨어와는 관계가 없습니다. 애드온 설치가 단말의 OS 설치·개조를 대신하지 않습니다.

GitHub 저장소:

```text
https://github.com/SeNcE-MS/front-panel-addon
```

[![Home Assistant에 저장소 추가](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FSeNcE-MS%2Ffront-panel-addon)

## 설치 전 준비

- 앱/애드온 설치 기능이 있는 **Home Assistant OS** 환경.
- 애드온 서버 지원 아키텍처: **amd64 / aarch64**. 표시 단말에는 웹 브라우저가 필요합니다.
- HA 서버와 표시 단말이 서로 통신할 수 있는 신뢰하는 내부망.
- 표시 단말에 고정 IP 또는 공유기의 DHCP 주소 예약을 권장합니다.
- 이 저장소는 **HACS용이 아니라 HA 앱/애드온 스토어용**입니다.

## 설치 방법

1. HA에서 **설정 → 앱 → 앱 설치**를 엽니다. 구버전 UI에서는 **설정 → 애드온 → 애드온 스토어**로 표시될 수 있습니다.
2. 우측 상단 **⋮ → 저장소**를 선택합니다.
3. 아래 주소를 붙여 넣고 **추가**합니다.

   ```text
   https://github.com/SeNcE-MS/front-panel-addon
   ```

4. 스토어의 **Front Panel** 저장소에서 같은 이름의 애드온을 선택하고 **설치**합니다. 목록이 안 보이면 스토어를 새로고침합니다.
5. 설치가 끝나면 아래 **최초 설정**을 진행한 뒤 **시작**합니다. 최초 설치는 HA 서버에서 이미지를 빌드하므로 시간이 걸릴 수 있습니다.
6. **Web UI 열기**를 눌러 편집기를 엽니다. HA 로그인으로 인증되며 별도의 장기 액세스 토큰을 입력할 필요가 없습니다.
7. 필요하면 **자동 시작**과 **사이드바 표시**를 켭니다. 업데이트는 사용자가 확인한 뒤 실행하는 것을 권장합니다.

## 최초 설정

애드온의 **구성** 탭에서 다음 항목을 설정하고 저장합니다. 변경 후에는 애드온을 재시작합니다.

- **`viewer_ip`**: 표시 단말의 실제 사설 IPv4 주소. 정확히 한 주소만 허용합니다. 예를 들어 단말 주소가 `192.168.1.50`이면 그 값을 입력합니다. CIDR, 호스트 이름, 쉼표로 구분한 여러 주소는 지원하지 않습니다. **공유기에서 주소를 고정하고 이 항목을 설정하는 것을 권장합니다.** 비워 두면 이 단말별 IP 제한만 적용하지 않습니다.
- **`editor_password`**: 직접 접속 편집기용 **16자 이상의 고유한 비밀번호**. 표시용 비밀번호와 다르게 설정합니다. HA Ingress 편집기는 HA 인증을 사용하지만, 아래 자동 표시 모드를 쓰려면 이 암호도 반드시 설정해야 합니다.
- **`viewer_password`**: 표시 화면의 선택적 인증입니다. **빈 값**이면 위 편집용 비밀번호를 설정한 상태에서 허용된 내부망 단말이 별도 로그인 없이 표시 화면에 들어갑니다. 인증이 필요하면 **숫자 6~8자리 PIN** 또는 **16자 이상 비밀번호**를 설정합니다. 앞자리 0이 있는 PIN은 문자열로 유지합니다.

> 두 비밀번호를 모두 비워 둔 최초 상태는 내부망 자동 표시 모드가 아닙니다. 편집은 HA의 Web UI로 먼저 진행하고, 표시 단말을 사용하기 전에 위 옵션을 설정하세요. 저장소에는 개인 비밀번호·IP·엔티티 연결값이 포함돼 있지 않습니다.

네트워크의 기본 외부 포트는 **18764/TCP**입니다. 다른 애드온과 충돌하면 애드온 네트워크 설정에서 변경하고, 아래 접속 주소에도 변경한 포트를 사용합니다.

## 표시 단말에서 접속

표시 단말 브라우저에서 다음 주소를 엽니다. `HA_IP`를 본인 HA 서버의 내부 IP로 바꿉니다. 포트도 본인 설정을 따릅니다.

```text
http://HA_IP:18764/
```

예를 들어 HA 서버가 `192.168.1.10`이면:

```text
http://192.168.1.10:18764/
```

- `viewer_ip`는 **HA 서버가 아니라 표시 단말의 IP**입니다.
- IP 제한을 설정하면 다른 PC/휴대폰에서 위 주소를 여는 것은 403으로 차단되는 것이 정상입니다. 편집은 HA의 **Web UI 열기**를 이용하세요.
- 표시용 인증을 설정한 경우 해당 PIN/비밀번호로 로그인합니다. 자동 표시 모드이면 바로 화면이 나옵니다.
- 필요하면 단말 브라우저를 전체화면/키오스크 모드로 설정합니다. 브라우저 자동 시작·단말 Wi-Fi·백라이트·모션 센서 점등은 별도 단말 설정이며 이 애드온이 자동 구성하지 않습니다.

## 화면과 기기 연결

1. HA의 애드온 **Web UI**에서 방을 추가하거나 이름·순서를 정리합니다.
2. 카드마다 이름·아이콘·엔티티를 선택하고 표시 여부를 정합니다. 센서는 방별로 추가·정렬할 수 있습니다.
3. 실제 켜기/끄기가 필요한 카드에서만 **실제 제어 허용**을 켭니다. 선택한 `light`·`switch`·`automation`만 제어하며 다른 도메인은 상태 표시 용도입니다.
4. 자동화 카드는 **활성화/비활성화**입니다. 자동화의 ‘지금 실행’ 기능은 제공하지 않습니다.
5. 7개 색상 테마와 라이트/다크, 카드 크기·간격·글자, 토글 표시, 애니메이션을 설정합니다. 글라스도 라이트·다크를 모두 지원합니다.
6. **홈 화면**을 사용하려면 옵션을 켜고 날씨·상세 센서·세탁기·건조기·할 일 목록을 필요한 만큼 연결합니다. 홈은 기본적으로 꺼져 있습니다. 세탁/건조 상태와 할 일은 읽기 전용이며 기기 시작/정지나 할 일 편집 기능이 아닙니다.
7. **저장** 후 표시 화면을 확인합니다. 설정 저장이나 테마 변경 자체가 기기 명령을 실행하지는 않습니다.

연결하지 않은 값은 미연결/확인 불가로 표시됩니다. 실제 집의 엔티티 ID를 직접 선택해야 하며, 다른 집의 설정을 그대로 가져와 작동한다고 가정하지 마세요.

상단 아이콘은 HA의 `www` 아래에 둔 PNG/JPG/WEBP/GIF 파일(2MB 이하)을 상대 경로로 지정할 수 있습니다. 예: HA `www/front-panel/icon.png` → 편집기에 `front-panel/icon.png`. 외부 이미지 URL·SVG·상위 폴더 경로는 지원하지 않습니다.

## 보안

- **신뢰하는 집 내부망 전용 HTTP 서비스**입니다. 인터넷 포트포워딩·외부 공개 프록시로 이 포트를 직접 노출하지 마세요. 외부 접속이 필요하면 VPN 등 별도 보안 경로를 설계하세요.
- 자동 표시 모드는 허용된 단말에서 카드 제어도 가능하다는 뜻입니다. `viewer_ip`와 편집 비밀번호를 설정하고 신뢰하는 단말만 사용하세요. IP 제한은 암호화나 강력한 기기 신원 인증을 대체하지 않습니다.
- 직접 접속 편집 로그인은 IP 제한이 적용되는 범위 안에서 `/login?role=editor`로 접근하며, 일반적으로는 HA의 인증된 Web UI 사용을 권장합니다.
- 표시 권한에는 전체 설정 쓰기 권한이 없습니다. 서버는 저장된 표시·제어 허용 카드만 제어 대상으로 사용합니다. HA 토큰은 서버 안에서만 사용하고 브라우저에 전달하지 않습니다.
- 직접 접속 로그인 세션은 재시작 시 사라져 다시 로그인해야 할 수 있습니다. 별도 표시 인증을 쓰지 않는 자동 표시 모드와 구분하세요.
- 설정 JSON 내보내기에는 집 이름과 엔티티 ID가 들어갈 수 있습니다. 공개 저장소나 공유 글에 그대로 올리지 마세요.

## 업데이트

1. 편집기의 **JSON 내보내기**와 HA 백업으로 현재 구성을 보관합니다.
2. 스토어에서 업데이트를 확인하고 설치합니다.
3. 재시작 후 화면과 연결 상태를 확인하고 표시 브라우저를 새로고침합니다.

설정은 애드온 내부의 `/data/panel/panel.json`에 저장돼 일반적인 재시작·업데이트 후 유지됩니다. **애드온 삭제 후 새 설치는 데이터 보존을 보장하지 않습니다.** 로컬 애드온과 GitHub 저장소 애드온은 서로 다른 설치 항목이므로, 기존 사용자는 원본을 삭제하지 말고 JSON을 내보낸 뒤 새 설치에 가져오세요. 비밀번호·IP·네트워크 옵션은 새 애드온에서 다시 설정해야 합니다.

## 문제 해결

- **스토어에서 보이지 않음:** 저장소 URL과 앱 지원 아키텍처를 확인하고 스토어를 새로고침합니다.
- **설치/시작 실패:** 애드온 로그, 이미지 다운로드 가능 여부, 포트 충돌 및 비밀번호 길이를 확인합니다.
- **직접 주소에서 403:** 접속한 단말의 IP와 `viewer_ip`가 일치하는지, 같은 내부망인지 확인합니다. `X-Forwarded-For` 같은 헤더로 제한을 우회할 수 없습니다.
- **직접 주소에서 로그인할 수 없음:** 옵션을 저장하고 재시작했는지 확인합니다. 두 암호를 모두 빈 값으로 두면 자동 표시되지 않습니다. 설정 복구는 HA의 인증된 Web UI를 이용합니다.
- **기기가 미연결/값 없음:** 엔티티 연결, HA 원본 상태와 사용 가능 여부를 확인합니다. 도어락·커튼 등 모든 도메인을 제어하는 범용 리모컨은 아닙니다.
- **업데이트가 안 보임/화면이 예전 모습:** 스토어와 표시 브라우저를 각각 새로고침합니다. 설치 소스가 다른 항목을 보고 있지 않은지도 확인합니다.
