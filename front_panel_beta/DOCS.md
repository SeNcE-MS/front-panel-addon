# Front Panel Beta

Music Assistant 시험 베타

정식 Front Panel과 별도로 설치되는 공개 베타입니다.

## 설치·사용

1. 저장소에서 **Front Panel Beta**를 설치합니다.
2. 구성의 `viewer_ip`에 표시 단말의 내부 IP를 입력합니다.
3. 시작 후 **Web UI 열기**에서 화면을 설정합니다.
4. **Music Assistant 사용**을 켜고 서버를 연결합니다. 상세 음악 연동에 Music Assistant API 토큰을 입력하고 인증을 확인합니다. 음악 서비스와 스피커는 Music Assistant에서 먼저 설정하세요.
5. 표시 단말에서 `http://HA_IP:18765/`로 접속합니다. `HA_IP`는 본인 HA 서버의 내부 IP입니다.

정식 버전의 18764 포트와 별도의 공간을 사용하며 기존 설정은 자동으로 복사되지 않습니다. 필요하면 정식 편집기에서 JSON을 내보낸 뒤 베타에서 가져오세요. 설정 원본은 보관하세요.

이전 연결 설정의 `music_assistant_url`은 호환용 선택 옵션입니다.

베타에는 오류가 있을 수 있습니다. 내부망에서만 사용하고 인터넷에 포트를 공개하지 마세요. 토큰·개인 설정은 공유하지 마세요.
